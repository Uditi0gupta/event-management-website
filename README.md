# EventHub - Event Management Website

A modern, responsive Event Management Website built for the K Explore Web Designing task.

## Features
- **Hero Section**: Includes a live event countdown timer.
- **Dynamic Event Cards**: Displays events with image, date, venue, and description.
- **Search & Filter**: Search events by title/venue or filter by category (Technical, Cultural, Workshop).
- **Event Modal**: Dynamic details pop-up for individual events.
- **Registration Form**: Includes client-side JavaScript validation and LocalStorage saving.
- **Dark/Light Mode**: Full theme toggle support.

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES6+)

## How to Run
1. Clone the repository: `git clone <YOUR-REPO-URL>`
2. Open `index.html` in any web browser.
